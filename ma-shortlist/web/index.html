Changing managing agent? Start with a fair shortlist.

For condo councils in Singapore. Find managing agents that already run condos near yours, send them all the same request for proposal, and compare what comes back like-for-like.

Free to use, and no agent pays to be listed.

How it works

  1. Shortlist 3 to 5 agents

    Enter your development. See which agents manage condos near you and of a similar size, whether they've been keeping their clients, and which of their developments you could ask for a reference.

  2. Send one standard RFP

    Build a request for proposal with your scope of services, a timeline worked back from your start date, and one price schedule every agent must fill in. Print it, save it as PDF or edit it in Word.

  3. Compare quotes like-for-like

    Type in each quote. See the yearly cost with GST, the cost per unit and per condo-manager hour, and a weighted score you can adjust. Print a summary for the council minutes.

Why this exists

Most councils change managing agent once every few years, with new council members each time. Agents are hard to find, quotes arrive in different formats, and it's hard to tell what's included. That makes the choice slower and less fair to owners than it should be.

This site puts the public information in one place and gives every council the same simple process. It was started by a condo owner after going through an agent change.

No agent pays to be listed or ranked, and there's no commission. The shortlist uses only public data, and how it works is published in full. It's a starting point for getting quotes, not a rating of quality.
